# Planning

How the agent should handle requests to plan something, as opposed to
implementing directly.

See [_format.md](_format.md) for the entry format.

---

### Auto-document plans under /plan
- **Rule:** Whenever the dev asks for help planning something, write the plan to a file under `/plan` automatically — don't wait to be asked to document it.
- **Why:** The dev wants a persistent, reviewable record of every plan without having to remember to request it separately each time.
- **Applies to:** all
